# Comparison Activity

## Prompt

Compare two language models from this module using the following questions:

1. Which model seems better for writing tasks?
2. Which model seems better for coding or tool use?
3. Which model would you choose for local deployment and why?
4. What is one weakness you noticed in each model?

## Suggested format

Write a short paragraph or bullet list for each model, then finish with a conclusion about which one you would recommend for a specific use case.

## Example use case

You might compare Claude and an open-source model for a privacy-focused chatbot project, or compare OpenAI and Gemini for a multimodal assistant.
